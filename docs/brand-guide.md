# Kinetix OS brand guide

Kinetix is a lightweight, Debian-based KDE desktop project. Its identity should be distinct, readable, and accessible rather than imitating another distribution.

## Visual direction

- Primary blue: `#2878e8`
- Highlight blue: `#56a5ff`
- Light background: `#f4f8ff`
- Dark text: `#172b4d`
- Breeze icons and KDE-compatible visual conventions
- Keep contrast and keyboard accessibility in mind

## Product principles

- A compact general-purpose desktop by default
- Optional use-case bundles rather than a preinstalled tool dump
- Debian packages and documented configuration
- No claims of performance gains without repeatable measurements
- Clear distinction between mockup, roadmap, and working OS behavior

Do not reuse other distributions' names, logos, wallpapers, or proprietary assets in a way that suggests endorsement.
