# Запуск и установка Kinetix OS на Windows, macOS и Linux

## Два способа попробовать Kinetix OS

1. **В браузере:** откройте сайт проекта. Интерактивная демоверсия показывает макет рабочего стола, меню, ярлыки и демонстрационное окно. Она не запускает настоящие Linux-приложения и не заменяет установленную ОС.
2. **В виртуальной машине:** скачайте ISO и запустите его в VirtualBox, VMware или UTM. Это настоящий Kinetix OS, работающий в отдельном виртуальном компьютере.

## Где скачать ISO

- Откройте вкладку Actions репозитория и выберите успешный запуск workflow **Build and boot-test Kinetix ISO**.
- Внизу страницы откройте Artifacts и скачайте архив `kinetix-iso-...`.
- Распакуйте архив. В нём должен быть `Kinetix-OS-amd64.iso` и `SHA256SUMS`.
- Используйте только артефакт успешной сборки. CI-артефакты временные; опубликованные релизы будут доступны дольше.

Если успешной сборки нет, готового проверенного ISO пока нет — не устанавливайте незавершённый образ на основной компьютер.

## Windows 10/11

1. Установите Oracle VirtualBox или VMware Workstation.
2. Создайте виртуальную машину типа Linux / Debian (64-bit).
3. Выделите минимум 4 ГБ RAM (лучше 8 ГБ), 2 виртуальных CPU и 30 ГБ диска.
4. Подключите `Kinetix-OS-amd64.iso` как виртуальный оптический диск.
5. Запустите виртуальную машину и выберите Live-загрузку. Сначала проверьте систему без установки на виртуальный диск.
6. Для установки внутри VM запустите установщик Debian, если он включён в конкретную сборку. Не выбирайте физический диск Windows.

Альтернатива: записать ISO на USB и загрузить с него совместимый x86-64 компьютер. Это не установка Kinetix как приложения Windows.

## macOS

### Mac с Intel
1. Установите VirtualBox (если версия macOS и VirtualBox поддерживают ваш Mac), VMware Fusion или другой совместимый гипервизор.
2. Создайте VM Debian Linux x86-64 с 4–8 ГБ RAM, 2 CPU и диском от 30 ГБ.
3. Подключите ISO и загрузите Live-систему.

### Mac с Apple Silicon (M1/M2/M3/M4 и новее)
Текущая сборка Kinetix — amd64/x86-64. Она не является нативной ARM-сборкой. Для запуска понадобится эмуляция x86-64 в UTM/QEMU; производительность может быть заметно ниже, а некоторые функции виртуального оборудования могут не работать. Нативную поддержку Apple Silicon нельзя обещать до выпуска и тестирования отдельного ARM64-образа.

## Linux

1. Установите VirtualBox, VMware или QEMU/KVM из репозиториев своего дистрибутива.
2. Создайте VM Debian 64-bit с 4–8 ГБ RAM, 2 CPU и диском от 30 ГБ.
3. Подключите ISO и загрузите Live-систему.

Для QEMU/KVM пример:

```sh
qemu-system-x86_64 \
  -enable-kvm -m 4096 -smp 2 \
  -cdrom Kinetix-OS-amd64.iso \
  -boot d -drive file=kinetix-test.qcow2,format=qcow2,if=virtio
```

Перед этим создайте виртуальный диск:

```sh
qemu-img create -f qcow2 kinetix-test.qcow2 30G
```

## Установка на физический компьютер

Kinetix OS — Linux-дистрибутив, а не приложение, которое можно установить поверх Windows или macOS. На совместимом x86-64 ПК можно загрузиться с USB и установить систему на отдельный раздел или диск, если в ISO имеется и проверен установщик. Сделайте резервную копию данных. Ошибка выбора диска может удалить существующую систему.

- Windows: можно оставить Windows и установить Kinetix рядом (dual boot) на поддерживаемом ПК.
- Linux: можно установить рядом с другим Linux, используя отдельный раздел.
- Mac Intel: установка на физическое устройство зависит от модели, драйверов, загрузчика и поддержки Apple hardware; не гарантируется.
- Mac Apple Silicon: нативная установка не поддерживается текущим amd64 ISO.

## Важные ограничения

- Текущая официальная цель образа: x86-64 / amd64.
- Запуск в VM — наиболее универсальный способ попробовать систему, не меняя основную ОС.
- Веб-демо — только демонстрация интерфейса, не эмулятор ОС.
- QEMU boot test не подтверждает работу Wi-Fi, Bluetooth, звука, графического ускорения, сна или установщика на каждом устройстве.
- Не используйте ISO на основном компьютере, пока не проверили Live-режим, резервную копию и совместимость оборудования.
