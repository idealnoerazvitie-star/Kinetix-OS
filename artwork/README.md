# Kinetix OS artwork

`kinetix-wallpaper.svg` is the original 1920×1080 Kinetix OS desktop wallpaper. The live image installs it at `/usr/share/backgrounds/kinetix/kinetix-wallpaper.svg` and configures KDE Plasma to use it as the default background for new users. The Change Wallpaper application also accepts SVG images.
