A Linux desktop that feels familiar.

Kinetix OS is a community Linux distribution built on Debian and KDE Plasma. It uses familiar Papirus application icons, Breeze desktop styling, real Linux applications and the customization tools already built into KDE.

View source on GitHubExplore software bundles

A practical desktop, not a mock interface

The installed system runs KDE Plasma. Application icons come from Papirus and each application's own desktop entry. Files, System Settings, Discover, Konsole, notifications, networking and window management are native Linux components.

Familiar icons

Papirus icons and Breeze styling provide a consistent Linux desktop without emoji-based app tiles.

Change Wallpaper

A native Kinetix launcher opens a file picker and applies your chosen image to the Plasma desktop.

Software Center

KDE Discover manages Debian packages and optional Flatpak applications from configured sources.

Software for different workflows

Optional bundles cover productivity, internet, creative work, multimedia, development, electronics, science, security learning, accessibility and system maintenance. Install only the tools you need.

Use kinetix-bundle --list to see bundles, kinetix-bundle --dry-run creative to preview, or sudo kinetix-bundle creative to install one.

PC gaming and classic games

The gaming bundle includes Steam, Lutris, RetroArch, DOSBox, ScummVM and open-source games. Heroic Games Launcher and Bottles are available from Flathub. Commercial titles such as GTA require a legitimate copy and their own game files; Kinetix does not redistribute copyrighted games.

Project status

Kinetix OS is an early distribution project. Automated Debian package checks, live-build validation and QEMU boot tests run in GitHub Actions. Hardware support and game compatibility still require testing on real devices.
