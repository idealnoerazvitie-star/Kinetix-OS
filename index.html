На каких системах попробовать

Windows 10/11macOSLinux

Для Windows, macOS и Linux — запуск в VirtualBox/VMware/UTM из ISO. Нативная установка Kinetix как замены Windows или macOS не поддерживается. Для Apple Silicon нужна ARM-сборка, которой пока нет.

Демо не запускает настоящие приложения и не имеет доступа к файлам компьютера.
